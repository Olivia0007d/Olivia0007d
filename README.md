### 🌸 About Me & Development Philosophy

Hi, I'm **Olivia** 👋 — an Android developer who cares about clean architecture, thoughtful UI, and code that a human can actually read. I build apps the honest way: real logic over shortcuts, and craft over automation.

- ✨ **Specialization:** Android App Development — Kotlin & Jetpack Compose
- 🛠️ **Core Focus:** Performance optimization, neat UI/UX, and section-aware navigation
- ⚡ **Philosophy:** Authentic code and genuine human logic always beat cheap automation
- 🌱 **Currently Learning:** Advanced Android architecture, clean patterns, and Compose internals
- 🎯 **Current Goal:** Refining workflows and building elegant, impactful mobile software
